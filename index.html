Task 2: Master the Basics of a Programming Language

Choose one programming language of your choice and learn its fundamentals. You can refer to the resources linked below, or you can use any other source of your choice.

  • Java: https://www.learnjavaonline.org/
  • C: https://www.learn-c.org/
  • C++: https://www.learn-cpp.org/

Task 3: Sorting and Searching Algorithms

Learn and write code for fundamental sorting and searching algorithms. At a minimum, you must cover:

  • Searching: Linear Search, Binary Search
  • Sorting: Bubble Sort, Selection Sort, Insertion Sort, Quick Sort

(Feel free to try more advanced algorithms as per your time availability!)

Task 4: Learn GitHub Basics & Regular Contributions

Version control is essential for software engineering. Learn the basics of Git and GitHub using the following references, or any of your own:

  • GeeksforGeeks: Introduction to GitHub
  • YouTube: Git & GitHub Crash Course

Actionable: Install Git, create a GitHub repository named SSE_Task1, and make regular contributions to it until the deadline. You must push the codes for the basics and algorithms you learn in Tasks 2 and 3 to this repository.

Task 5: Mandatory Social & Council Knowledge Task

Follow our official Instagram page: @sse.dtu. Go through the page and familiarize yourself with the team.

Requirement: You must know all the Senior Council members and their respective positions by the upcoming Full Body Meet.
